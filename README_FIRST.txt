COIN COLLECTOR - MIXED PARK COIN EDITION

This update is based on your uploaded 60-coin / 5-minute Coin Collector project.

Changes:
- Coins are no longer placed only in straight lines on the road.
- 16 coins are on the perimeter roads.
- Other coins are spread across grass areas, winding garden paths, and reachable raised platforms.
- Added a pond, gazebo, benches, flower beds, shrubs, extra park greenery and garden paths.
- Added small garden hurdles to make some grass-side coin routes more challenging.
- Kept the 60-coin objective, 5-minute timer, human character, controls and win/game-over flow.

Open the project in Unity. After scripts compile, the existing Editor builder should automatically create Assets/CoinCollector.unity if it does not exist. If needed, use Tools > Coin Collector > Generate Game Scene. Then open Assets/CoinCollector.unity and press Play.

Controls: WASD move, mouse look, Left Shift run, Space jump, Escape unlock mouse, R restart after game over/win.

Note: This uses the legacy Input Manager. Set Active Input Handling to Both or Input Manager (Old) if Unity asks.
