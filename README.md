# 🪙 COIN COLLECTOR – 3D GAME

## 📌 About the Project

Coin Collector is an interactive 3D game developed using **Unity 6 and C#**. The game provides an engaging environment where players can explore different areas, move through roads, grass, and park surroundings, and collect coins placed throughout the game world.

The main goal is to collect all available coins while exploring the 3D environment. This project demonstrates fundamental game development concepts, including player movement, collision detection, object interaction, game mechanics, and score management.

## 🎯 Project Objectives

- Develop an interactive 3D game using Unity.
- Design an attractive and playable game environment.
- Implement smooth player movement and controls.
- Create a coin collection mechanism.
- Detect collisions between the player and collectible objects.
- Track the number of collected coins.
- Understand the fundamentals of Unity game development and C# scripting.

## 🎮 Game Features

### 1. 3D Game Environment
- Designed a 3D environment with roads, grass, and park areas.
- Provides an interactive space for player exploration.
- Includes different locations for coin collection.

### 2. Coin Collection System
- Includes 60 collectible coins.
- Coins are placed at different positions throughout the environment.
- Players can collect coins by moving the character towards them.
- Uses collision detection to identify coin collection.

### 3. Player Movement
- Allows players to navigate through the game environment.
- Supports movement using keyboard controls.
- Provides interactive gameplay.

### 4. Score Tracking
- Tracks collected coins.
- Updates the collection count during gameplay.
- Encourages players to collect all available coins.

### 5. Interactive Gameplay
- Combines player movement, environment exploration, and coin collection.
- Provides a simple and engaging gaming experience.

## 🚀 Installation and Setup

Follow these steps to run the project on your system:

1. Clone the repository:

```bash
git clone https://github.com/2303a51355/gaming.git
```

2. Open Unity Hub.
3. Select **Add Project from Disk**.
4. Choose the downloaded Coin Collector project folder.
5. Open the project using Unity 6.
6. Wait for Unity to import the required assets.
7. Open the game scene.
8. Click the Play button to start the game.

## 🕹️ How to Play

1. Start the game in Unity.
2. Use the keyboard to control the player.
3. Explore the roads, grass, and park areas.
4. Move towards the coins to collect them.
5. Collect all 60 coins available in the game.
6. Track your collected coin count.
